# Radeberg

Open-World-Spiel fürs Handy (Godot 4.7.2) im Geist von GTA San Andreas – eigene Insel „Radeberg“ mit Ghetto, Altstadt,
Downtown, Hafen, Bahnhof, Berg mit Wald, Wüste mit verlassenem Flugplatz und Autobahnring.

## Testversion installieren
1. Auf GitHub unter **Releases** (oder Actions → letzter Lauf → Artefakt) die `radeberg.apk` herunterladen.
2. Auf dem Handy öffnen und „Installation aus unbekannten Quellen“ erlauben.

## Steuerung
- **Touch:** links Stick (erscheint dort, wo du tippst), rechts wischen = Kamera. Im Auto GAS, BREMSE (= rückwärts), HAND, NOS, RAUS.
- **Neigen:** Einstellungen → „Lenken: Handy neigen“ (Mitte wird beim Umschalten gespeichert, „NULL“-Knopf setzt sie neu).
- **Xbox-Controller (Bluetooth):** wird automatisch erkannt – linker Stick laufen/lenken, rechter Stick Kamera,
  RT Gas, LT Bremse/Rückwärts, RB Handbremse, X NOS, Y Ein-/Aussteigen, A Springen, B Rennen, Start Pause, Back Karte.

## Inhalt dieser Version (0.1)
- ganze Insel begehbar und befahrbar, jedes Auto kann man nehmen, Verkehr und Passanten
- Minikarte + große Karte mit Symbolen
- Kleiderladen „Stoffwechsel“, Werkstatt „Radeberg Customs“ (Lack, Neon, Motor, NOS, Reparatur)
- Zuhause: Speichern
- Taxi-Job (in ein Taxi steigen → TAXI)
- 56 Fahr-Missionen aus dem Katalog spielbar (Pause → Missionen): Transporte, Lieferungen, Zeitrennen, Autodiebstahl, Abschleppen, Flucht, Eskorte, Bergung
- Motorsound, Vibration bei Unfällen, Android-Zurück-Taste öffnet das Pausenmenü

Der Missionskatalog (112 Missionen, Jobs, Immobilien, Geschäfte) liegt in `assets/data/missionen.json`; Kampf-Missionen, Immobilien, Taxizentrale und Logistikzentrum folgen in den nächsten Versionen.
